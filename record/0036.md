# Record 0036

The gate's scratch file is moved out of the book's directory.

`vps gate` writes a throwaway `GateEval.lean` on every run — including the pre-commit hook's
own run — to `#eval` the book against the staged facts. It was written inside `lean/Vjs/`,
which is exactly the scope [2026] VPS 30 protects with `recordRequired`.

The consequence was circular and only visible once VPS 30 existed: every gate run dirtied a
protected path, so every commit needed a record entry justifying the gate's own working notes,
and the commit that tried to untrack the file was itself denied by the statute for touching
that directory.

The file now lives at `lean/GateEval.lean`, outside any protected scope, and the ignore
pattern covers both locations.

This is the third instance today of one lesson, and it is worth stating as a rule rather than
an anecdote: **a protected path makes file placement constitutional.** Where a statute names a
directory, everything written there — including a tool's own transient output — becomes
subject to that statute, and the tool cannot exempt itself. Put scratch outside the scope, or
do not protect the scope.
