# Record 0026

Kernel integrity check added to `foundry doctor`, and named as debt.

Foundry vendors VPS's kernel. Six modules (World, Instrument, Legitimacy, Gate, Precedent,
Proofs) are byte-identical to canonical at `~/projects/vibe-proof-system/kernel/Vps`;
Genesis.lean legitimately differs by exactly one line, this jurisdiction's own sovereign
digest, which is the single sanctioned per-repo edit under §21.8. Book.lean and
Examples.lean are generated per repo and are not invariant either.

Nothing enforced that correspondence. `lean/Vps/DIGESTS.json` now records the six digests
and doctor fails on drift, naming the module.

This is deliberately a digest pin — the mechanism the Charter already uses for genesis —
and not a lock-file treadmill. It carries a demolition date: delete the file and the check
when VPS becomes a pinned lake dependency, at which point one copy of the constitutional
text exists upstream and the correspondence problem is dissolved rather than policed. The
blocker for that move is that `genesisDigest` is a `def` inside the shared engine, so a
dependency cannot supply a per-repo value; parameterising it is an upstream change that
forces re-proof of the whole kernel.

ASSESSMENT.md's warning about watchers watching watchers is the reason this is written down
with an expiry rather than left to grow. A watcher named as debt is different from one that
is simply added.
